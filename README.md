# X-Fan：X (Twitter) 铁粉与回访审计

一个 Chrome 扩展：在你自己浏览 X 的时候，被动记下页面本来就会加载的数据（粉丝、关注、推文、点赞通知），在本地算出两个榜单：

- **受邀回访榜**：你去别人帖子下互动后 7 天内，回来评论或点赞你原创帖的人。
- **自来水铁粉榜**：你没主动找过他，他自己来你原创帖下互动的人。

另外有「未回关清单」和铁粉圈圈图、海报生成。

## 隐私与安全

- 只读取 X 页面自己发出的请求的返回内容，**不额外请求 X 的接口**。
- **不会**自动点赞、关注、取关、发帖或私信。
- 数据只存在你自己浏览器的本地存储里，不上传到任何服务器，不请求第三方服务。
- 只申请 `x.com`、`twitter.com`、`pbs.twimg.com`（头像图片）三个网站的权限。

## 安装

1. 下载本仓库：点页面上方绿色的 **Code → Download ZIP**，解压到一个固定的文件夹（之后不要删除或移动它）。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择解压后的 **`chrome-extension`** 文件夹（里面有 `manifest.json` 的那一层）。
4. 打开 `https://x.com` 并登录，**先打开一次你自己的主页**。右下角悬浮窗显示出 `@你的账号`，就是识别成功了。

支持 Chrome 111 及以上版本，其他 Chromium 浏览器未测试。

## 使用

- **⚡ 90s 增量**（悬浮窗或大屏上的按钮）：依次打开你的主页、通知、回复、粉丝页、关注页并自动翻页，补采新数据，约 1～5 分钟。
- **🔄 全量深采对账**（大屏上的按钮）：把粉丝、关注名单翻到底，并移除已经取关的人，约 3～6 分钟。被移除的人只是挪到另一个列表，可以恢复。
- **📊 双榜大屏**：查看榜单、导出 CSV、生成海报。

巡检和对账会占用一个 X 标签页并自动跳转、翻页。**开始前请关掉没发完的草稿**，巡检期间不要在那个标签页里操作。

第一次用建议先跑一次全量深采，之后每天跑一次增量。

## 已知局限

- 名单准确度依赖翻页是否翻到底；网络慢或被 X 限流时，对账会拒绝执行，并在提示里写明原因，库里的名单不会被改动。
- 对账后，名单里可能残留少量没有 API 资料的账号（完成提示会写出人数）。这些账号不影响榜单排名。
- X 改版可能导致采集失效。

## 更新

下载新版本覆盖原文件夹后，在 `chrome://extensions/` 点 X-Fan 卡片上的刷新按钮。数据保存在浏览器里，不会因为更新而丢失。

**不要**在 `chrome://extensions/` 里点「移除」：移除扩展会删掉它保存的全部数据。需要的话先在大屏点「📤 导出备份 JSON」。

更新记录见 [`chrome-extension/CHANGELOG.md`](chrome-extension/CHANGELOG.md)。
