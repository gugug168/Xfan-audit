## 二、v10 双榜评分标准（唯一真相源）

> Python 端 (`Xfan-audit/scripts/return_visit.py`) 与插件 JS 端 ([scorer.js](scorer.js)) **100% 逐位对齐**。

### 1. 铁律前提與数据清洗
- **硬前提**：对方必须在我的 `followers`（粉丝）名单中；未关注我的人一律不进铁粉榜。
- **剔除自赞与连带赞**：通知页的点赞必须剔除自己（`db.me`）。新版采集器直接读通知的 `template.from_users`（`schema: 2`），这是权威的点赞者名单，多人聚合通知（「A、B 和另外 N 人赞了你」）中的每个人都计入；只有旧数据（无 `schema`）才走「剥离引用推文原作者」的启发式，以排除转推/引用带来的连带赞（如旧版被误判的 `@berryxia`）。
- **修补引用/转推作者覆盖 Bug**：解析推文 JSON 时严格跳过 `quoted_status_result` 与 `retweeted_status_result`，确保我的 324 篇原创主帖作者不被内嵌引用帖作者覆盖。

### 2. 双榜分流逻辑（7 天归因窗口）
对于粉丝在我的帖子下的每一次有效互动（时刻 $t_2$）：
- 若在 $[t_2 - 7\text{天}, t_2]$ 窗口内，我有主动回复过该粉丝的记录（时刻 $t_1$） $\implies$ 归入 **🎯 榜一：受邀回访榜（有来有往）**。
- 若在 $t_2$ 前 7 天内我从未主动回复过他，他自己主动找上门互动 $\implies$ 归入 **🔥 榜二：自来水铁粉榜（未触达主动登门）**。

### 3. 动作权重与分档门槛

| 计分项 | 🎯 榜一：受邀回访榜 | 🔥 榜二：自来水铁粉榜 | 去重与防刷口径 |
|---|---|---|---|
| **基础分** | 关注我 `+5`，互关再 `+3` | 关注我 `+5`，互关再 `+3` | 每人仅计一次 |
| **评论我原创主帖** | **`+40 分 / 帖`** | **`+40 分 / 帖`** | 按我的原创主帖 ID 去重（同帖回 10 条也只算 1 帖） |
| **我原创帖下多轮对话** | **`+12 分 / 条起`**（同帖 `×0.68` 递减） | **`+12 分 / 条起`**（同帖 `×0.68` 递减） | 按根帖分桶逐条衰减，跨天不重置 |
| **净点赞我原创主帖** | **`+4 分 / 帖`** | **`+4 分 / 帖`** | 按我的帖子 ID 去重，排除基线旧赞与连带双赞 |
| **别人帖子串里接话** | **`+1 分 / 天`** | `0 分`（不计入自来水） | 按自然日去重 |

**档位划分与 S/A 硬门槛**：
- **S 档**：总分 $\ge 70$ 且满足 **S/A 硬门槛**（至少评论过 1 篇我的原创主帖，或互动过的我的原创帖跨 $\ge 2$ 个发帖日）。
- **A 档**：总分 $\ge 40$ 且满足 **S/A 硬门槛**。
- **B 档**：总分 $\ge 15$（或分数达标但未满足 S/A 硬门槛被降档）。
- **C 档**：总分 $< 15$。

## 三、三阶段产品演进路线图 (Roadmap)

### ✅ 第一阶段（Phase 1）：个人实盘闭环与社交裂变海报（已完成 · `v1.0.0` ~ `v1.6.0`）
- [x] `MAIN` world 零额外请求双 Hook（`fetch` + `XHR`）与 DOM 头像实时采集
- [x] `chrome.storage.local` (`unlimitedStorage`) 本地无限容量增量数据库 + 内置 `seed-baseline.json` 自动合并
- [x] `⚡ 90 秒每日增量巡检`（遇到已采集推文 ID 自动早停）与 `🔄 全量深采对账`
- [x] `v10` 双榜评分引擎（榜一受邀回访榜 + 榜二自来水铁粉榜 + 榜三未回关清理表）
- [x] **🪐 同心圆「铁粉圈圈图」+ 荣誉榜卡片生成器 (`v1.6.0`)**：
  - 支持 3 种画面样式（同心圆+卡片合体 / 纯享同心圆大方图 / 经典双列卡片）
  - 支持多维筛选（按榜单 / 按 S、A、B 档位 / 按前 N 名 / 清空重选手工点选）
  - 支持在线编辑海报标题、副标题、底部签名及每位上榜铁粉的昵称与互动文案
  - 自动生成配套 `@` 铁粉感谢推文

### 🚀 第二阶段（Phase 2）：多时间窗口趋势对比与「周度掉队预警」（下一步迭代 · `v1.6.0`）
- **核心价值**：不仅看「累计谁最好」，还要看「这周谁新晋、谁掉队」。
- **功能规划**：
  1. **时间范围切片器**：在大屏顶部增加 `最近 7 天 / 最近 14 天 / 最近 30 天 / 全部历史` 切换开关，无需重采数据即可按时间切片重算双榜。
  2. **新晋铁粉 & 沉默预警标记**：
     - `🆕 本周新晋 S/A 档`：在海报和榜单上自动加亮「新面孔」徽章，优先点名表扬激励。
     - `💤 昔日 S 档近期沉默`：过去是 S 档但最近 14 天 0 互动的老铁，单独提醒你去他主页串门破冰。
  3. **自定义账号自动识别增强**：彻底零配置适配任意安装了插件的 X 创作者账号（自动从页面导航栏提取当前登录 `me` 账号与高清头像）。

### 🌐 第三阶段（Phase 3）：众包「全网高回访 X 创作者公共红榜」（远期生态 · `v2.0.0`）
- **核心理念**：你给别人导流，别人用同一个插件生成他的「铁粉圈圈图」再发推——形成病毒式创作者互推网络。
- **功能规划**：
  1. **插件一键打包分发 (.zip)**：提供干净的空库发行版打包脚本，任何 X 友解压加载即可审计自己的账号。
  2. **脱敏签名推荐包汇总 (`📤 导出 S/A 档推荐签名包`)**：
     - 每位创作者可自愿导出自己认证的 S/A 档高回访铁粉脱敏包（仅含 `@handle`、头像、被认证为 S/A 档次数，**绝不含任何私密推文或黑名单**）。
  3. **「全网最讲义气 X 创作者公共红榜」聚合页**：
     - 汇总多位创作者提交的推荐包，计算每位 X 友**被多少位不同创作者认证为 S/A 档真铁粉**，生成全网公认的「高回访值得深交 X 友总榜」。
